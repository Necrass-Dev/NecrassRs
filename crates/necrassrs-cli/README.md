`necrassrs-cli` installs the `necrass` command, which creates a new Axum or Actix Web GraphQL project with SDL, a Cargo build script, generated-contract wiring, and an initial resolver.

```sh
cargo install necrassrs-cli --locked
necrass init my-api
```

The target directory must be new or empty. See the [installation guide](https://necrass.rs/docs/installation/) for prerequisites, framework selection, and the first request.
