`necrassrs-http` contains framework-independent GraphQL-over-HTTP response media-type negotiation shared by the NecrassRs Axum and Actix Web adapters.

Applications normally use [`necrassrs-axum`](https://docs.rs/necrassrs-axum) or [`necrassrs-actix`](https://docs.rs/necrassrs-actix) instead of depending on this crate directly.
