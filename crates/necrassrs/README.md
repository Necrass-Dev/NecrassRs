`necrassrs` is the execution core for SDL-first GraphQL applications in Rust. It validates requests, dispatches generated resolver contracts, and produces GraphQL responses while applications retain ownership of routing and request context construction.

Resolver contracts and dispatch code are generated by [`necrassrs-build`](https://docs.rs/necrassrs-build). HTTP integration is provided by [`necrassrs-axum`](https://docs.rs/necrassrs-axum) and [`necrassrs-actix`](https://docs.rs/necrassrs-actix).

NecrassRs is pre-1.0. Query and mutation execution are available; generated subscription routing remains unsupported. See the [project documentation](https://necrass.rs/docs/) for current capabilities and setup instructions.
