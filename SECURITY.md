# Security Policy

## Supported versions

This policy covers all public packages maintained in this repository.

During the 0.x release series, only the latest stable release receives
security fixes. Earlier releases are not supported. For example, once
0.4.1 is released, 0.4.0 is no longer supported.

## Reporting a vulnerability

Please report suspected security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Necrass-Dev/NecrassRs/security/advisories/new).
Do not disclose vulnerability details in public issues or pull requests.

Include the affected package and version, reproduction steps or a minimal
proof of concept, and the potential security impact.

Please coordinate public disclosure with the maintainers so that a fix
or mitigation can be prepared.
